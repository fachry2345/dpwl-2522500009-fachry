# pertemuan-01
1. kesinambungan PWD, DPW, DPWL
Jawab: PWD merupakan pondasi pembuatan web, di sini kita pertama kali mengenal HTML, CSS, JavaScript, PHP dasar. DPW merupakan lanjutan dari PWD di matkul ini kita memahami PHP lebih terstruktur. DPWL merupakan lanjutan dari DPW yang dimana kita sudah fokus dalam pengembangan Model, View, Controller.

2. perbedaan PHP Terstruktur dan MVC
Jawab: PHP Terstruktur menggunakan satu file untuk membuat suatu web sedangkan MVC dipisahkan menjadi tiga bagian yaitu Model, View, Controller.

3. Fungsi Model, View, dan Controller
Jawab: 
- Model bertanggung jawab terhadap data fungsinya mengakses dan mengelola data dan berinteraksi     dengan database

-View Bertanggung jawab terhadap tampilan kepada pengguna fungsinya menampilkan data dan membuat form, tabel, katalog.

-Controller Bertanggung jawab terhadap alur dan proses aplikasi fungsinya menerima request dan menghubungkan model dengan view.

4. Alur request-response MVC
Jawab: Browser, controller, model, database, model, controller, view, browser.

6. kesimpulan P1
Kesimpulan P1:
P1 membahas kesinambungan PWD, DPW, dan DPWL serta pengenalan konsep MVC. MVC memisahkan Model untuk data, View untuk tampilan, dan Controller untuk mengatur proses. Pemahaman ini menjadi dasar untuk mengembangkan aplikasi web yang lebih terstruktur.
